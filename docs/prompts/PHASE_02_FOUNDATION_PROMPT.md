Use `guide.docx` and the Phase 1 documents as authoritative context.

Implement the minimum production foundation for States, Markets, Hook Partners, Market Associates, Hook Dispatch Hubs, external Logistics Providers, and Paystack without reviving Booth, Vendor portal, or internal Fleet semantics.

Before implementation:

1. Resolve the negotiation floor bypass and design signed, expiring negotiated quotes.
2. Define a payment-provider trust contract and migrate MVP checkout to verified Paystack webhooks/status queries.
3. Define new domain models independently of retained legacy collections.
4. Produce reversible migration/backfill plans.
5. Align seed fixtures only after the new contracts exist.

Preserve public response envelopes and build adapters at explicit compatibility boundaries.
